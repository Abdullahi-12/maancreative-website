# Maan Creative Agency website
Next.js + React + TypeScript + Tailwind CSS.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Deploy to Vercel
1. Upload this project to a new GitHub repository.
2. In Vercel, click Add New → Project → Import Git Repository.
3. Select this repository, keep Framework Preset = Next.js, click Deploy.
4. Go to Project Settings → Domains and add maancreative.com and www.maancreative.com.
5. Verify the DNS values Vercel displays. In Namecheap Advanced DNS, update the A and CNAME records accordingly. Keep email-related records intact.

Note: Vercel Hobby is restricted for commercial usage. Use a plan appropriate for a business website.
